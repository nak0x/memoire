## Overview

Ce dossier documente la phase de documentation du sujet 1 « Les objets numériques dans les enfances alternatives ». Il vise à rassembler contexte, données et études sur les usages du numérique dans l'éducation et les enfances, notamment alternatives, en croisant lecture de littérature et enquête de terrain (entretiens, observations). L'objectif est d'identifier les axes de recherche pertinents, de cerner les causes profondes d'un éventuel rejet des outils numériques, et de repérer les réponses déjà apportées par les acteurs du terrain.
