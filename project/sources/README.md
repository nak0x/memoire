# Sources

Appareil critique du projet. Tout ce qui est affirmé dans un rendu doit pouvoir être
retrouvé ici en moins d'une minute.

## Ordre de lecture

1. **[[verifications]]** — ⚠️ *à lire en premier*. Ce qui ne tient pas dans la note de
   cadrage, et le fait nouveau du 14 août 2026.
2. **[[table-de-sourcage]]** — chaque affirmation de la note → sa source et son statut.
3. **[[bibliographie]]** — toutes les références, avec ce que j'en tire et ce qu'elles ne
   permettent pas de dire.
4. **[[chiffres-cles]]** — les chiffres seuls, avec leur définition exacte.

## Conventions

- **Clés** `[MAJUSCULES-ANNÉE]`, définies dans [[bibliographie]] et utilisées partout.
- **Langues** : [FR] / [EN], comme dans [[alternative-childhood-educations-research]].
- **Statuts** : ✅ source primaire · 🟢 source secondaire fiable · ⚠️ écart · ❓ non sourcé ·
  🔵 opinion assumée.
- **Dates de consultation** obligatoires pour toute page web.
- **PDF** : copie locale dans `pdf/` quand la licence le permet, pour ne pas dépendre de
  la disponibilité d'un site le jour de la soutenance.

## Deux règles que je m'impose

1. **Aucun chiffre sans ligne dans [[chiffres-cles]].** La passe du 07/09 a montré que
   100 % de mes erreurs venaient de chiffres écrits de mémoire.
2. **Une source dit ce qu'elle dit.** Chaque entrée de [[bibliographie]] porte un
   « ne permet pas de dire ». Une source qui n'a pas de limite notée est une source que
   je n'ai pas lue.
